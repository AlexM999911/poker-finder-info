Help test Poker Finder

Add your first test venue and game

These steps require Poker Finder 0.5.0 or later. On iPhone, install Apple’s TestFlight app and accept the Poker Finder invitation supplied by Omniabi. On Android, use the signed beta APK supplied directly by Omniabi and follow Android’s installation prompts; Google Play testing is not available yet. The Android build requires a 64-bit phone running Android 7 or later. This page is a guide, not an app download or invitation link. Install the latest beta before starting.

  1. Sign in with your own account. Use email on either platform, or Apple sign-in on an Apple device, and complete the age/profile form truthfully. Google sign-in is currently restricted to the configured test audience.
  2. Open Host → Set up a venue. Begin the name with “TEST —”. Use invitation-only access for private tests. Select facilities and add house rules clearly saying this is a technical test with no real event or payment. Do not publish a real home address.
  3. Add a schedule. Choose a future date, “Free play” stakes and a small number of seats. You receive 30 free venue posting credits; each published date uses one. There is no purchase or automatic charge.
  4. Invite another tester privately. Show the venue invitation code and share it with them. They open Venues → Have a private invitation? and enter the code. Both people need the installed beta app as well as the venue code.
  5. Test the player and host flow. The player opens the game, reads the rules and requests a seat using a truthful introduction choice. The host accepts or declines in Host. Check Saved and Updates on the player’s phone.
  6. Try photos, video and Maps. The host can add three photos and one video from the game page. Use non-sensitive test media. Maps can search the area or public venue; private directions use an address the host shares separately. No route needs to be travelled.
  7. Clean up and send feedback. Delete your test games, then the venue, when finished. On iPhone, use TestFlight’s Send Beta Feedback. On Android, email alex@omniabi.com. Include the app version, phone model and steps that led to a problem. Avoid passwords and private addresses in screenshots.

Android game updates appear in the Updates inbox; Android lock-screen push notifications are not enabled in this beta.

Account → Delete account removes your account and its shared content. Deleted game dates do not refund posting credits. Do not organise actual gambling or collect payments as part of a fictional test.

Need access or help? Contact alex@omniabi.com.
